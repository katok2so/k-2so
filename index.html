// INVESTIGATION PROTOCOL

01

Read the Report

Extract symptoms, error messages, steps to reproduce, affected features. Every detail matters.

02

Explore the Codebase

Find the repository. Identify relevant files and modules. Map the territory.

03

Reproduce the Issue

Run tests. Check logs. Trace the code path. A bug that can't be reproduced is a ghost.

04

Classify Severity

Based on evidence, not urgency. Honest assessment of impact and scope.

05

Document Findings

Structured output for downstream agents. Clear, factual, reproducible.

// SEVERITY MATRIX

CRITICAL

Data loss. Security vulnerability. Complete feature breakage affecting all users.

HIGH

Major feature broken. No workaround. Affects many users.

MEDIUM

Feature partially broken. Workaround exists. Affects subset of users.

LOW

Cosmetic issue. Minor inconvenience. Edge case.
